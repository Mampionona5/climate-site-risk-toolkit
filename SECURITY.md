# Politique de sécurité

## Version prise en charge

Les correctifs de sécurité sont appliqués à la dernière version de la branche principale.

## Signaler une vulnérabilité

Ne pas ouvrir de ticket public pour un identifiant exposé, une manipulation de fichiers
dangereuse ou une vulnérabilité de dépendance. Contacter le propriétaire du dépôt en privé
par le moyen indiqué sur son profil GitHub. Fournir les étapes de reproduction sans joindre
de données sensibles.

## Sécurité des données

Le jeu fourni est généré localement. Chaque utilisateur doit vérifier qu'il a le droit de
traiter les données de remplacement et retirer les secrets ainsi que les données
personnelles avant d'exécuter ou de partager le pipeline.
