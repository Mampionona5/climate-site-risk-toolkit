# Traçabilité et droits d'usage

## Périmètre

Ce dépôt a été créé le 7 octobre 2026 pour présenter une chaîne de traitement climatique
réutilisable et documentée.

Il mobilise le packaging Python, le traitement NetCDF, les données tabulaires, l'extraction
spatiale, le contrôle qualité, la restitution, les tests et la documentation technique.

## Éléments exclus

Aucun code source, donnée, modèle, document, figure, paramètre, résultat de recherche,
logo ou système de nommage interne provenant du CIRAD, de BRIO ou d'ARBOCARTO n'est inclus.

Le projet ne reproduit pas la chaîne scientifique du stage, la modélisation des populations
de moustiques, l'analyse du risque de dengue, les territoires étudiés ni les scénarios
climatiques utilisés à cette occasion.

## Sources et données d'exemple

- Le jeu d'exemple est généré localement avec une graine aléatoire fixe.
- La liste des sites est fictive.
- Le contrat de données et les indicateurs ont été conçus spécialement pour ce projet.
- L'implémentation repose sur les API publiques des bibliothèques Python et sur des pratiques
  générales d'ingénierie des données.

## Contributions futures

Toute donnée externe, tout exemple de code ou toute méthode adaptée devra être ajouté ici
avec sa source, sa licence, sa date d'accès et son usage prévu avant d'être enregistré dans
l'historique Git.
